05 / ALGORITHM OVERVIEW

How Booth's Algorithm Works

Booth's algorithm performs signed binary multiplication using two's complement representation. It examines consecutive bits of the multiplier to determine whether addition, subtraction or no operation is required.

01

Initialize Registers

Set the accumulator A to zero. Load the multiplier into Q, the multiplicand into M, and initialize Q-1 to zero.

02

Examine Bit Pair

Examine the least significant bit of Q (Q₀) and the previous bit (Q-1) to determine the required operation.

03

Perform Operation

Depending on the bit pair, add M to A, subtract M from A, or leave A unchanged.

04

Arithmetic Right Shift

Perform an arithmetic right shift on the combined registers A, Q and Q-1. Repeat the process for the selected bit width.

OPERATION REFERENCE

Booth's Decision Rules

Based on Q₀ and Q-1
Q₀ Q-1 Operation Register Action
00 No Operation A remains unchanged
01 Addition A = A + M
10 Subtraction A = A - M
11 No Operation A remains unchanged
Important: The arithmetic right shift is performed after the selected operation in every iteration. The process continues until all bits have been processed.
06 / PROJECT INFORMATION

About the Project

Understanding computer arithmetic through interactive simulation.

Making Binary Arithmetic Easier to Understand

BoothLab is an interactive educational simulator developed to demonstrate Booth's Multiplication Algorithm, a technique used for multiplying signed binary numbers.

The project provides a visual representation of the algorithm's internal working by displaying register values, arithmetic operations and bit shifting at every iteration.

Instead of displaying only the final answer, BoothLab allows users to follow the complete calculation process and understand how the result is obtained.
