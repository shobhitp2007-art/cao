BoothLab
Interactive Signed Binary Multiplication Simulator
BoothLab is a browser-based educational simulator for Booth's
Multiplication Algorithm. It demonstrates signed binary multiplication
using two's complement representation and the registers A, Q, M,
and Q-1.

The simulator helps students follow the algorithm step by step rather
than displaying only the final answer.

Features
- Positive and negative integer inputs.
- Selectable signed bit widths: 4, 5, 8, and 16 bits.
- Input validation for the selected signed-number range.
- Live display of the A, Q, M, and Q-1 registers.
- Booth's decision rules:
  - 00 --- No operation
  - 01 --- Add M to A
  - 10 --- Subtract M from A
  - 11 --- No operation
- Arithmetic right shift after each iteration.
- Start, Next Step, Previous, Auto Play/Pause, and Reset controls.
- Final product displayed in binary and decimal.
  
Technologies
- HTML5 --- page structure
- CSS3 --- layout, styling, and responsive design
- JavaScript --- input validation, binary operations, algorithm
  execution, and interface updates

How to Run
1. Open the project folder in Visual Studio Code or another code
   editor.
2. Open index.html in a modern web browser.
For local development, you can use the Live Server extension in
Visual Studio Code:
1. Install Live Server.
2. Open index.html.
3. Right-click in the editor and select Open with Live Server.
There is no build step and no npm install requirement.

How to Use
1. Enter an integer in Multiplicand (M).
2. Enter an integer in Multiplier (Q).
3. Select the bit width.
4. Select Start Simulation.
5. Use Next Step to advance through the iterations.
6. Use Previous to view the preceding saved state.
7. Use Auto Play to advance automatically. Select Pause to
   stop.
8. Select Reset to clear the simulation.
Inputs must be whole numbers within the signed range for the selected
bit width:

Booth's Algorithm: Decision Rules
The algorithm examines the pair formed by the least significant bit of
Q (Q₀) and the previous bit (Q-1).

  Q₀ Q-1   Action
  00       No addition or subtraction
01       A = A + M
10       A = A - M
11       No addition or subtraction

After the selected action, an arithmetic right shift is performed on the
combined registers. The process repeats for the selected number of bits.

Implementation Notes
- The JavaScript implementation uses BigInt for integer arithmetic.
- The accumulator and multiplicand use an additional working bit
  during the calculation.
- The simulator stores the register states generated by the algorithm.
  Previous and Next navigate through these saved states.
- Auto Play advances through the stored states at a fixed interval.
  
Limitations
- Only integer inputs are supported; fractions are not accepted.
- This is an educational software simulation, not a hardware
  implementation.
- A modern browser with JavaScript BigInt support is required.
